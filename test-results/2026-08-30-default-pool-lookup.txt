build it returns null.

WHAT IS ALREADY EXCLUDED
------------------------
The memory context is not missing. The harness has reported
cur_mem_ctx = 0x4400170 on every run for days -- a valid, non-null context. So
the lookup is failing with a good context, which leaves the index or the table
it indexes.

Also excluded, all by measurement rather than argument: the null pool at
activate (retail does the same), the pool object's zero fields (retail's are
zero too), the vtable (correctly populated, real .text address at the failing
slot), and the .bss address the object landed on (empty in retail as well).
