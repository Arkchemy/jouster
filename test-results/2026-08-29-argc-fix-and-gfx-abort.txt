RULED OUT BY MEASUREMENT, NOT BY ARGUMENT
------------------------------------------
- Guest memory corrupting the host: impossible. Every guest access masks with
  & (PPC_MEM_SIZE - 1) (ppc_runtime.h:384 and :451), so a wild guest pointer
  cannot leave the 1GB arena.
- Unlocked console race between the two threads: no. Both the game thread's
  checkpoint() and the main thread's consoleUpdate take g_console_mutex; a
  previous race there was already fixed and commented.
- Ignored applet suspend messages: no. The frame loop is driven by
  appletMainLoop() (main.c:1738).

LEADING CAUSE: NO MEMORY LEFT FOR THE GRAPHICS DRIVER
------------------------------------------------------
Every run has reported, from its very first line:

    process memory: total=3189MB used=3185MB

4MB of headroom at startup. The cause is structural:

    .text  159,534,181   the recompiled game
    .bss 1,073,788,120   static PpcSharedMemory g_shared (the 1GB guest arena)

~1.19GB of image, and libnx's default __libnx_initheap then commits ALL
remaining process memory as the malloc heap. The graphics driver allocates
lazily and outside that heap, which is exactly why it fails partway into a
run rather than at consoleInit, and why the timing moves between runs.

This is a strong candidate, not a proven cause. It fits every observation --
the abort is in an allocation path, the process is at 99.9% utilisation, and
the failure point varies -- but one log cannot distinguish it from a graphics
fault that merely happens to allocate.

CHANGES
-------
1. main.c now overrides __libnx_initheap with a fixed 128MB inner heap, so
   libnx never commits "everything available" and the driver has room. Host
   heap use is only newlib stdio, the FS shim and Bink's host buffers -- the
   guest arena is .bss, not malloc -- so 128MB is generous.
   Verified linked: nm resolves __libnx_initheap to main.c:826, and .bss grew
   by exactly 134,217,712 bytes.
2. main.c logs host headroom every 300 frames:
       host mem @frame N: used=..MB total=..MB free=..MB
   If the theory is right, free shrinks toward zero before the abort. If it
   stays flat, the theory is wrong and the next run says so in one number.
